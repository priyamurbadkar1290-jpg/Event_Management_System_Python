📝 Event Management System
A command-line Python application to add, view, and delete events with real-time countdown tracking to each event date.

🛠️ Built With

Python 3
datetime module — for date parsing, validation, and countdown calculation


✨ Features

Add events — Enter an event name and date (YYYY-MM-DD format); the system validates the date format and stores it
List events — Displays all upcoming events sorted chronologically, with a live countdown showing days remaining until each event
Delete events — Remove any event by name with confirmation feedback
Input validation — Handles invalid date formats gracefully with clear error messages
Menu-driven interface — Simple numbered menu for easy navigation
